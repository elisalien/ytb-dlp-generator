================================================================
   yt-dlp Studio  -  Mode d'emploi (Windows)
================================================================

Telechargeur video 4K / 8K et convertisseur local, avec une
interface dans le navigateur. Portable : tout reste dans ce dossier.

----------------------------------------------------------------
 INSTALLATION (une seule fois)
----------------------------------------------------------------

1. Double-cliquez sur  install.bat
   -> Il telecharge yt-dlp, FFmpeg et Deno dans le dossier "bin".
      Deno est le moteur JavaScript requis par YouTube.
   -> Si Windows SmartScreen apparait : "Informations complementaires"
      puis "Executer quand meme".
2. Facultatif : create-shortcut.bat cree le raccourci "yt-dlp Studio"
   sur le Bureau (clic droit -> Epingler a la barre des taches).

----------------------------------------------------------------
 UTILISATION
----------------------------------------------------------------

1. Double-cliquez sur  launch.bat  (ou le raccourci).
   -> L'interface s'ouvre dans le navigateur (Firefox en priorite).
   -> Une fenetre "yt-dlp Studio - serveur" s'ouvre REDUITE : c'est
      elle qui travaille. La fermer arrete les telechargements.

2. Onglet TELECHARGER
   - Collez vos liens (un par ligne), ou glissez un lien / un onglet
     sur le panneau.
   - Choisissez un format : Compatible (par defaut), Ultime, 4K, 2K,
     Full HD, HAP, HAP Q, MP3 ou Frames (une image PNG par frame).
   - Destination : bouton "Choisir..." (memorise).
   - Cliquez sur "Telecharger" (ou Ctrl + Entree).

   Rangement automatique :
   - Lien de playlist ou de chaine -> dossier au nom de la playlist,
     fichiers numerotes dans l'ordre.
   - Plusieurs liens d'un coup     -> sous-dossier "Lot <date heure>".
   - Un seul lien                  -> directement dans la destination.

3. Onglet CONVERTIR
   - Choisissez un fichier sur le PC.
   - Preregage : MP4 compatible, MP4 HQ, HAP, HAP Q ou MP3.
   - Largeur maximale facultative (reduit seulement).
   - Le fichier produit est cree a cote de la source
     (ex. clip-compatible.mp4, clip-hap.mov).

4. La file d'attente affiche la progression, le temps restant,
   le journal et un bouton pour ouvrir le dossier.

5. Favori navigateur : Options avancees -> glissez le bouton
   "yt-dlp Studio" dans la barre de favoris. Sur une page video,
   cliquez-le : le lien arrive dans l'interface.

Mode manuel : Options avancees -> "Commande equivalente" -> Copier,
puis collez-la dans terminal.bat.

----------------------------------------------------------------
 MISE A JOUR DES OUTILS
----------------------------------------------------------------

Automatique au lancement (au plus une fois toutes les 12 h).
Pour forcer : double-cliquez sur  update.bat.
 - yt-dlp : canal nightly (suit les changements de YouTube).
 - Deno   : auto-mise a jour.
 - FFmpeg : re-telecharge UNIQUEMENT si une version plus recente existe.

Erreur 403 ou "caller does not have permission" : laissez "Cookies
du navigateur" active (Options avancees), avec Firefox connecte a
YouTube, puis relancez update.bat.
