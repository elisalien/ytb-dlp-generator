================================================================
   yt-dlp Studio  -  Mode d'emploi
================================================================

UN TELECHARGEUR VIDEO 4K SIMPLE, AVEC UNE INTERFACE GRAPHIQUE.

----------------------------------------------------------------
 INSTALLATION (a faire une seule fois)
----------------------------------------------------------------

1. Double-cliquez sur  install.bat
   -> Il telecharge automatiquement les outils necessaires
      (yt-dlp, FFmpeg, Deno) dans le dossier "bin".
      Deno est le moteur JavaScript requis par YouTube pour
      recuperer les formats haute qualite (4K).
   -> Une connexion internet est requise.
   -> Si Windows SmartScreen apparait : "Informations complementaires"
      puis "Executer quand meme".

----------------------------------------------------------------
 UTILISATION
----------------------------------------------------------------

1. Double-cliquez sur  launch.bat
   OU sur le raccourci  "yt-dlp Studio"  (Bureau / dossier du projet).
   Pour l'epingler a la barre des taches : clic droit sur le raccourci
   -> "Epingler a la barre des taches".
   -> L'interface s'ouvre dans votre navigateur.
   -> Une fenetre noire "Terminal" s'ouvre aussi : c'est normal,
      c'est la que les videos se telechargent.

2. Dans l'interface, onglet "Telecharger" :
   - Collez vos liens YouTube (un par ligne)
   - Choisissez un profil (par defaut : Compatibilite maximale)
     Profil "Frames" : cree un dossier par video avec toutes les
     images PNG (frame_00001.png, ...) — attention au volume disque.
   - Cliquez sur "Copier la commande"

3. Cliquez dans la fenetre noire "Terminal", faites un CLIC DROIT
   (ce qui colle la commande), puis appuyez sur ENTREE.

4. La video (ou le dossier de frames) est enregistree dans
   le sous-dossier  Telechargements.

----------------------------------------------------------------
 MISE A JOUR DES OUTILS
----------------------------------------------------------------

Double-cliquez sur  update.bat  quand vous le souhaitez.
Le script verifie d'abord si des mises a jour existent et ne
telecharge que le necessaire :
 - yt-dlp : canal nightly (suit les changements YouTube / erreurs 403).
 - Si 403 Forbidden ou "caller does not have permission" (playlist
   privee / detection bot) : cochez "Cookies navigateur" dans Options
   avancees et choisissez votre navigateur (celui connecte a YouTube),
   puis regenerez la commande. Vous pouvez aussi relancer update.bat.
 - Deno   : auto-mise a jour.
 - FFmpeg : re-telecharge UNIQUEMENT si une version plus recente existe.

----------------------------------------------------------------
 NOTES
----------------------------------------------------------------

- FFmpeg est inclus : laissez le champ "FFmpeg" VIDE dans l'interface.
- Pour TOUT re-telecharger de zero, relancez install.bat ;
  pour ne mettre a jour que le necessaire, lancez update.bat.
- Tout reste dans ce dossier, rien n'est installe ailleurs sur le PC.
