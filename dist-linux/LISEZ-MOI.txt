================================================================
  yt-dlp Studio — Mode d'emploi (Linux)
================================================================

Interface locale pour telecharger et convertir vos medias.
Portable : tout reste dans ce dossier.
Compatible x86_64 et ARM64.

----------------------------------------------------------------
INSTALLATION (une seule fois)
----------------------------------------------------------------

1. Ouvrez un Terminal
2. cd chemin/vers/dist-linux
3. chmod +x install.sh launch.sh update.sh
4. bash install.sh

----------------------------------------------------------------
UTILISATION
----------------------------------------------------------------

1. bash launch.sh
2. Dans l'interface :
   - Telecharger : URLs + profil → Copier la commande
   - ffmpeg commandes : fichier source + preset → Copier
3. Collez dans le Terminal (Ctrl+Shift+V), puis Entree

Telechargements → dossier Téléchargements/
Conversions → chemin indique dans la commande

----------------------------------------------------------------
MISE A JOUR
----------------------------------------------------------------

bash update.sh  — met a jour uniquement ce qui est obsolete
bash install.sh — reinstalle tout depuis zero

----------------------------------------------------------------
NOTES
----------------------------------------------------------------

- Laissez le champ FFmpeg vide (deja inclus)
- Presets video standards : H.264 + AAC + MP4 (compatible VLC)
- Presets ffmpeg : MP4, MP3, HAP / HAP Q
