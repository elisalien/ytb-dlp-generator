🎬 yt-dlp Studio

Téléchargez ou convertissez vos médias avec des commandes prêtes à coller, en privilégiant des sorties réellement compatibles.

Génère une commande yt-dlp prête à coller. Les profils vidéo standards sont maintenant ré-encodés en H.264 + AAC + MP4 pour éviter les surprises sur VLC, TV, mobiles et logiciels de montage.
Convertit vos fichiers locaux avec ffmpeg. Donnez un fichier source, choisissez un preset, puis collez la commande dans le terminal fourni par l’outil.
Si laissé vide, un nom de fichier cohérent est proposé automatiquement selon le preset choisi.
